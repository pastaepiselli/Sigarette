# Sigarette — recensioni di sigarette

Sito per consultare e recensire sigarette italiane, ispirato a Letterboxd. Gli utenti possono assegnare un voto e scrivere recensioni, commentare quelle degli altri e salvare sigarette in liste personali.

## Componenti

- [`backend/`](backend/README.md): catalogo, recensioni, commenti, profili utente, liste personali e istruzioni per avviare lo stack locale.
- `frontend/`: interfaccia web (da aggiungere).

## Tecnologie

Il backend utilizza:
- *Java 21*,
- *Spring Boot*,
- *PostgreSQL*,
- *ActiveMQ*,
- *Keycloak*
- *Docker Compose*.

I dettagli dell’architettura, delle API e dell’avvio sono documentati nel [README del backend](backend/README.md).
